输入框与 Task 面板
交互场景

按真实使用顺序拆分组件状态。每个场景独立说明发生条件、组件表现与操作效果，便于逐项评审。

范围：Composer + Task Dock形式：场景描述 + 状态描述 + 效果展示
Task 面板显示原则只有当 Agent 已将请求转化为可跟踪的执行步骤时才出现。进入工作状态并不等于已经形成 Task。

4

等待确认 · 输入区切换为意图确认

Task 需要用户决策时，不再使用对话内确认卡片，底部输入区直接切换为结构化确认面板。
出现条件

任务因授权、选项或必填参数而暂停时，普通输入框切换为结构化确认区域。

固定结构

问题、说明、选项或输入、确认按钮；确认或取消后再恢复普通输入框。
